# 01 — 人設設定

人設是整個計畫的地基。「不刻意」的前提是：**這個人設要建立在你自己真實的生活背景上**，你本來就會聊這個主題，帶貨才不突兀。

---

## 人設卡（預設：小資生活／開箱好物）

| 項目 | 設定 |
|---|---|
| **暱稱候選** | `小資的家` / `慢慢過生活` / `日常選物筆記` / `阿選 selects`（挑一個好記、帶生活感、可搜尋的） |
| **一句話定位** | 「一個租屋小資族，把每一塊錢花在刀口上，分享真的有用的好物。」 |
| **目標受眾** | 25–35 歲、租屋或小家庭、預算有限、重 CP 值、會爬文比價的人 |
| **背景故事** | 北漂／租屋、預算有限、愛研究 CP 值、踩過雷所以想幫大家避雷 |
| **核心動機** | 「省錢 + 踩雷過所以想幫忙」→ 讓帶貨變成「幫忙」而非「推銷」 |
| **語氣** | 口語、像跟朋友聊天、會講缺點、不浮誇 |
| **視覺識別** | 固定色調（奶茶／原木／米白暖色系）、固定版面模板、固定開場白與結尾語 |
| **露臉程度** | 半露臉（手部、生活場景為主，偶爾入鏡）——兼顧信任與經營壓力 |
| **更新頻率** | IG Reels 每週 3 支、限動每日、YT 每週 1 支（詳見 `03`） |

---

## 語氣範例：這樣說 vs 不要這樣說

| 情境 | ✅ 人設語氣 | ❌ 業配語氣 |
|---|---|---|
| 推薦一個收納盒 | 「我家浴室一直很亂，換了這個之後總算不用每天翻箱倒櫃了。缺點是深色容易看到灰塵，要勤擦。」 | 「這款收納神器必買！CP 值超高，錯過再等一年！」 |
| 介紹一支鍋 | 「用了三週，導熱真的快，但把手有點燙，建議搭隔熱手套。」 | 「廚房必備聖品，煎什麼都不沾，快搶購！」 |
| 帶連結時 | 「有需要的放留言連結，這是分潤連結，你買我會有一點回饋，但不影響你的價格 🙏」 | 「連結在這 ⬇️ 手刀下單！」 |

**原則**：講缺點、給使用情境、把價格立場講清楚。真實感 > 說服力。

---

## 視覺與版面規範（讓帳號一眼可辨）
- **主色調**：奶茶／原木／米白（暖色系，營造「生活感」而非「賣場感」）。
- **固定模板**：Reels 封面統一字型與色塊；貼文首圖固定留白比例。
- **固定用語**：
  - 開場白：「欸這個我要跟你講一下…」
  - 結尾語：「花錢前先看我，幫你避雷 👋」
- **精選分類**：`好物清單`、`踩雷回顧`、`收納`、`廚房`、`優惠情報`。

---

## 經營鐵律（違反就會垮）
1. **只推自己真的認同的東西**——沒用過不推。
2. **缺點一定講**——沒有完美商品，講缺點才可信。
3. **分潤一定揭露**——標「內含分潤連結／合作」。
4. **90% 內容不帶貨**——先當有用的人，再當推薦的人。
5. **不洗版促銷**——一週最多一次明確帶貨貼文。
