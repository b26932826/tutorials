# 05 — 貼文與影片文案範例

可直接複製套用的範本。共同原則：**先勾住 → 給價值/情境 → 講缺點 → 才帶連結 → 揭露分潤。**

---

## A. IG Reels 腳本範本（15–30 秒）

**主題：好物快閃（帶貨用，每週四）**
```
[0-3秒 勾子] （手拿商品）欸這個我要跟你講一下，租屋族真的會用到。
[3-15秒 情境] 我家浴室以前超亂，牙刷牙膏到處放。換了這個之後，全部收好還多出一個平面。
[15-22秒 缺點] 缺點先說：深色容易看到灰塵，要勤擦。可以接受再往下。
[22-28秒 CTA] 有需要留言區有連結，是分潤連結，你買我有一點回饋、不影響你的價格 🙏
[結尾] 花錢前先看我，幫你避雷 👋
```

**主題：踩雷分享（純價值，不帶貨）**
```
[勾子] 這三個廚房小物，拜託你不要買。
[內容] 一個一個講為什麼雷（附畫面）。
[結尾] 想看「值得買的版本」留言 +1，下支拍給你。
```

```

1️⃣ 折疊收納箱｜$299
   優點：能疊、能折。缺點：深色顯灰塵。

2️⃣ 門後掛勾｜$120
   ……

（每項都寫優缺點）

—
🔗 連結都放主頁 Linktree，怕你找不到我釘在限動精選「好物清單」。
＊內含分潤連結，你透過連結購買我會有小額回饋，價格不變，感謝支持 🙏

#租屋 #收納 #小資生活 #momo好物
```

## C. 限動帶貨話術（連結貼紙）
```
（畫面：商品使用中）
文字：用了三週的心得 → 滑下一頁
———
（下一頁）
文字：優點 X、缺點 Y，可接受再點連結
[連結貼紙：momo 追蹤連結]
小字：分潤連結，價格不變 🙏
```

## D. YouTube 範本

**標題公式**（含搜尋關鍵字 + 情境 + 數字）
- 「租屋族必看｜300 元有找的 5 個收納好物實測（含踩雷）」
- 「不沾鍋到底怎麼選？3 款實測比較，這款我留下了」

**資訊欄範本**
```
這支影片提到的商品（皆為 momo 分潤連結，透過連結購買我會有小額回饋，不影響你的售價，感謝支持 🙏）：

00:00 開場

...

追蹤我：

```

## E. 分潤揭露用語（擇一固定使用）
- 短版（限動/Reels）：「分潤連結，價格不變 🙏」
- 完整版（貼文/資訊欄）：「內含分潤連結，你透過連結購買我會有小額回饋，不影響你的售價，感謝支持。」
