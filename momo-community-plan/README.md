# momo 商品分潤社群經營計畫

用 **Instagram + YouTube** 經營一個社群，透過 momo 購物網「聯盟行銷（分潤）」做商品推廣——但**不刻意、不像業配帳號**。核心心法：**先給價值、再順便帶連結；你在分享生活，商品只是道具。**

## 這份計畫適合誰
- 想靠 momo 分潤創造被動收入，但不想當「硬推銷」帳號的人。
- 願意固定產內容、建立長期信任的個人經營者。

## 三個最重要的原則
1. **90% 價值 + 10% 帶貨**：多數內容不放連結，只負責被看見與建立信任。
2. **只推真心認同的東西，缺點照講**：第一次為抽成推爛貨，信任就崩、整個模式垮。
3. **一定揭露分潤**：標明「內含分潤連結」，誠實反而加分。

## momo 聯盟行銷機制（先懂再開始）
- 申請通過 → 取得專屬追蹤連結 → 他人透過你的連結下單即抽成。
- 抽成依品類不同（約 1%–8%；3C 低、生活/美妝/家居較高），且有 **Cookie 追蹤期限**（點連結後數日內下單才算）。
- 策略結論：主推**「決策快、單價中等、複購高」**品類（生活雜貨、收納、廚房小物、清潔耗材），避開需長考的高單價家電。

> 預設利基＝**小資生活／開箱好物**、人設＝**真實親切、可半露臉**。要改成育兒/美妝/料理或改走不露臉/知性評測，只需替換 `01` 人設與 `04` 選品清單，其餘架構通用。
