# 02 — 內容策略與平台分工

## 90% 價值 + 10% 帶貨（「不刻意」的關鍵配比）

| 類型 | 佔比 | 目的 | 放連結？ |
|---|---|---|---|
| **純價值內容** | ~60% | 教學、生活 vlog、踩雷分享 → 觸及與信任 | ❌ 不放 |
| **場景植入** | ~30% | 好物自然出現在生活畫面 | 留言／資訊欄 |
| **明確帶貨** | ~10% | 「本月回購清單」等直接推薦 | ✅ 明確放 |

> 心法：**你在分享生活，商品只是道具。** 反過來（先想賣什麼再湊內容），觀眾一眼看穿。

### 純價值內容題目範例（不帶貨也要能吸人）
- 「租屋族最容易忽略的 5 個收納死角」
- 「我踩過最雷的 3 個廚房小物（別買）」
- 「300 元以內改造出租套房質感」
- 「一週晚餐這樣備料，下班不崩潰」

## 平台分工：IG 與 YT 角色不同

### YouTube＝信任與深度
- 長影片：開箱、比較、教學。
- 搜尋長尾流量，一支好影片幫你帶貨半年以上。
- **連結放資訊欄**，最自然。
- 頻率：每週 1 支。

### Instagram＝頻率與親近感
| 格式 | 角色 | 帶貨方式 |
|---|---|---|
| **Reels** | 觸及新粉（短開箱、before/after、好物快閃） | 留言放連結 |
| **限動** | 日常帶貨主力 | 連結貼紙，看完即消失、壓力最低 |
| **貼文／精選** | 好物懶人包長期沉澱 | 導去主頁連結 |

## 導流動線（把觸及變成下單）

```
IG Reels（觸及新粉）
      │
      ▼
個人檔案 / 主頁
      │
      ├──▶ 限動精選（好物清單）
      │
      ├──▶ YT 深度影片（建立信任）
      │
      ▼
主頁連結頁（Linktree 或 momo 連結集中頁）
      │
      ▼
   momo 下單（分潤成立）
```

**重點**：IG 貼文本文不能點連結，所以一定要有「主頁連結頁」集中所有 momo 連結（用 Linktree 或自建連結頁），並在限動／貼文不斷提醒「連結在主頁」。
