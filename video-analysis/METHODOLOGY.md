# AI 影片風格拆解與複製方法論

針對「人物很正確 + 鏡頭切換有機制感」這類影片的逆向工程與生產指南。

---

## 一、先判斷:這支是怎麼做出來的?

拿到畫格後,依序回答四個問題,就能收斂出製作方式。

### Q1 人物在不同鏡頭間是否「同一個人」?

把兩個不同鏡頭的人物特寫並排,檢查五個錨點:

| 檢查點 | 一致 → 代表 | 漂移 → 代表 |
|--------|------------|------------|
| 瞳色、眼距、鼻樑高度 | 有角色鎖定機制 | 純文字 prompt 生成 |
| 髮際線、瀏海分線 | 參考圖或 LoRA | 每鏡頭獨立生成 |
| 服裝鈕扣數、口袋位置、配件 | 首尾幀控制 | 只有語意層一致 |
| 痣、疤、刺青等小特徵 | LoRA 自訓模型(最強) | 參考圖(中等) |
| 身形比例、肩寬 | 3D/真人來源 | 2D 生成 |

**判讀規則**:五角衣物細節都對 → 幾乎確定用了 **角色參考圖 (character reference)**;連痣、疤這種小特徵都穩 → 是 **LoRA 自訓** 或**真人拍攝**。

### Q2 是真人還是生成?

- **手部**:AI 生成在手指交疊、持物時最容易露餡,放大看指節數。
- **文字**:背景招牌、書本上的文字是否可讀。糊掉或亂碼 = 生成。
- **物理**:布料飄動、頭髮與肩膀的穿插、影子方向是否合理。
- **時間連續性**:同一鏡頭內背景物件會不會憑空變形(morphing)。

### Q3 鏡頭內的運動是「真運鏡」還是「生成的偽運鏡」?

- 真運鏡:視差正確(前景移動快於背景)。
- 偽運鏡:整張圖像縮放/平移(Ken Burns),或背景跟著主體一起扭曲。

### Q4 切換點的畫面關係

看 `cut_XXX_before.jpg` 與下一個 `shot_XXX.jpg` 的關係:

- 構圖相似、主體位置接近 → **匹配剪接 (match cut)**,刻意設計過。
- 景別跳一級(全景→中景→特寫) → 標準**三段式進場**。
- 完全無關但節奏整齊 → **卡點剪接**,對齊音樂節拍。
- 前一格已經開始模糊/變暗 → 有**轉場特效**(非硬切)。

## 二、人物一致性:四種技術與取捨

| 技術 | 一致性強度 | 成本 | 適用 |
|------|-----------|------|------|
| **文字 prompt 描述外貌** | ★ | 極低 | 不需要同一人反覆出現 |
| **角色參考圖 (cref / reference)** | ★★★ | 低 | 主流做法,3-20 個鏡頭夠用 |
| **首尾幀控制 (start/end frame)** | ★★★★ | 中 | 需要精準銜接的連續動作 |
| **LoRA 自訓角色模型** | ★★★★★ | 高 | 系列化內容、固定主角 IP |

### 實務組合拳(推薦)

1. **先定妝**:用文生圖產出一張**角色聖經圖**(character bible)——正面、半身、光線平均、背景乾淨。這張圖是全片的錨。
2. **產出多視角**:由聖經圖延伸出側面、背面、不同表情各一張,存成資料夾。
3. **每個鏡頭**:餵「對應視角的參考圖」+「該鏡頭的動作 prompt」。
4. **銜接鏡頭**:把前一鏡的**最後一格**當作下一鏡的**首幀**,動作就能連起來。

> 關鍵心法:**不要讓 AI 每次重新想像這個人**。每次都給它看同一張臉。

### 常見失敗與修法

| 症狀 | 原因 | 修法 |
|------|------|------|
| 轉頭後變成另一個人 | 只有正面參考圖 | 補側面參考圖 |
| 衣服細節每鏡不同 | 參考圖服裝不清楚 | 定妝圖拍全身、prompt 明寫鈕扣/配件 |
| 遠景時臉崩壞 | 臉部像素太少 | 遠景不給臉部特寫,或後製換臉 |
| 光線每鏡跳動 | 未指定光源 | prompt 固定「光從左前方 45 度」 |

## 三、鏡頭切換機制

### 核心觀念

AI 影片的鏡頭切換**幾乎不是模型生出來的**,而是後製剪接把各自生成的 clip 拼起來。所以「切換機制」= **分鏡設計 + 剪接節奏**,而非模型能力。

### 剪接節奏的量化標準

用 `analyze_video.sh` 跑出的「每分鐘刀數 (cuts per minute)」判斷語感:

| 每分鐘刀數 | 平均鏡頭長度 | 語感 | 典型應用 |
|-----------|------------|------|---------|
| 40+ | < 1.5 秒 | 轟炸感、資訊密集 | 短影音、預告片高潮 |
| 20-40 | 1.5-3 秒 | 明快、有推進力 | MV、廣告、社群內容 |
| 10-20 | 3-6 秒 | 敘事、可呼吸 | 說明片、劇情短片 |
| < 10 | > 6 秒 | 沉浸、情緒堆疊 | 電影感、氛圍影片 |

### 四種切換手法

1. **硬切卡點 (hard cut on beat)**
   最常用。把切點對齊音樂重拍。做法:先選定配樂 → 算出 BPM → 把時間軸格線設成 BPM → 每一刀都貼在格線上。
   *120 BPM 每拍 0.5 秒,常見切法是每 2 拍(1 秒)或每 4 拍(2 秒)切一次。*

2. **匹配剪接 (match cut)**
   前後鏡頭在**構圖、形狀或動作**上相似,觀眾感覺不到切換。設計法:讓前一鏡結尾與後一鏡開頭的主體位於畫面同一位置。

3. **J-cut / L-cut(聲畫錯位)**
   聲音比畫面早進(J-cut)或畫面切了聲音還延續(L-cut)。這是讓對話與旁白**不生硬**的關鍵,也是業餘與專業剪接最明顯的差別。

4. **景別階梯**
   同一場戲依「廣角建立 → 中景交代 → 特寫情緒」推進。切換時**跳一級**最自然;跳兩級有衝擊感;不跳級(中景切中景)會產生 jump cut 的跳動感,除非刻意為之。

### 讓切換不「跳」的三個一致性

即使每個 clip 是分開生成的,只要守住這三點就會像同一部片:

- **光線方向一致**:全片 prompt 都寫同一個光源方位。
- **色調一致**:最後套同一個 LUT / 調色檔,這是統一感最大的來源。
- **鏡頭語言一致**:決定全片是「手持晃動」還是「穩定器平移」,不要混用。

## 四、可複製的生產管線

```
1. 腳本      → 寫成一句一鏡的分鏡表(每鏡 3-8 秒)
2. 定妝      → 產出角色聖經圖 + 多視角參考圖
3. 選配樂    → 先選好!算出 BPM,決定剪接格線
4. 逐鏡生成  → 參考圖 + 運鏡 prompt,每鏡多生 3-4 個版本挑最好
5. 配音      → TTS 或真人錄音;需要對嘴則用數位人工具
6. 剪接      → 切點貼齊 BPM 格線,加 J/L-cut 處理語音
7. 音效      → 環境音 + 轉場音效(這步最常被略過,但差別極大)
8. 調色      → 全片套同一 LUT,統一感一次到位
```

### 生成 prompt 模板

```
[參考圖:character_ref_front.png]

鏡頭:中景,角色位於畫面右側三分點
動作:緩緩轉頭看向鏡頭,嘴角微微上揚
運鏡:鏡頭緩慢推近 (slow push in),幅度小
光線:主光來自左前方 45 度,柔和
氛圍:傍晚室內,暖色調
時長:5 秒
負面:不要變形的手、不要文字、不要鏡頭快速晃動
```

> **要點**:把「運鏡」「光線」「時長」拆成獨立欄位分開寫,比全部塞成一段散文的成功率高很多。

### 效率建議

- 每個鏡頭**生 3-4 個版本**,挑一個能用的。AI 影片的通過率本來就低(常見 1/3 到 1/4),把它算進時程。
- **先把全片用最低畫質串起來**確認節奏對,再回頭重生高畫質版本。不要一開始就追求單鏡完美。

## 五、用本工具做拆解

```bash
# 1. 把影片放進 source/
# 2. 執行(第二個參數是敏感度,快剪片用 0.35-0.45)
./analyze_video.sh source/影片.mp4 0.35

# 3. 產出
#    report/shot-list.md        鏡頭切換節奏表(含每刀時間碼)
#    report/contact-sheet-*.jpg 全片縮圖總覽
#    frames/shot_*.jpg          每個鏡頭的代表畫格
#    frames/cut_*_before.jpg    每個切點的前一格(比對銜接用)
```

拿到畫格後,回頭套用第一節的四個問題,填寫 `shot-list.md` 下半部的人工欄位,就完成一份完整拆解。
